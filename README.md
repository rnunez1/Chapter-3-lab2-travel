# Lab 3.2 - Travel Blog Visual Identity
**Student:** Ramon
**Folder:** /webdev/ch3/travel-blog/

## Files
- styles.css - single shared style sheet
- index.html, about.html, destinations.html, trip-planner.html, contact.html

## Steps
1. Created styles.css with a :root block defining seven CSS custom properties: --primary-color, --accent-color, --visited-color, --bg-color, --text-color, --heading-font, and --body-font.
2. Styled body, h1, h2, and p using var(), with Georgia headings, Trebuchet MS body text, and sizes stepping down from h1 (2.4em) to h2 (1.6em) to p (1em) for a clear typographic hierarchy.
3. Added the class selector .callout and applied it to the travel tip paragraph on index.html.
4. Added the id selector #site-footer to style the unique footer on each page.
5. Added :link, :visited, and :hover styles to every link in the shared navigation (and to links in main content), written in link-visited-hover order.
6. Linked styles.css to all five pages with <link rel="stylesheet" href="styles.css"> so the whole site shares one look.
7. Validated styles.css with the W3C CSS Validator (https://jigsaw.w3.org/css-validator/) and resolved all errors.
